# 车载平衡滚球运动控制系统 — 视觉部分交接文档

## 赛题背景

**2026 全国大学生电子设计竞赛（TI 杯赛区）H 题：车载平衡滚球运动控制系统**

核心任务：通过视觉摄像头（MaixCAM2）检测钢球在管道上的实时位置，利用 PWM 直驱舵机控制管道倾斜角度，使钢球稳定在管道中心。

## 已实现功能

### 1. 绿色管道透视矫正
- 上电自动识别绿色管道（LAB 色域阈值）
- 四点透视变换，将倾斜管道铺平为俯视图
- 只在第一帧执行一次，后续复用锁定角点

### 2. YOLO 钢球检测 + Kalman 追踪
- YOLOv5 实时推理钢球位置
- 单球 Kalman 追踪器（1D Kalman × 2，位置 + 速度估计）
- 贪心匹配 + coast 机制（丢帧补全）
- 前向预测补偿 NPU 推理延迟
- 追踪位置映射到 warp 俯视图，转为 cm 坐标

### 3. 双模式 PD 控制器（核心）
- **稳态模式**：KP=8, KD=4, DB=±0.2cm, 限速 300°/s
- **扰动模式**：KP=10, KD=7, DB=0, 限速 600°/s
- 模式切换：|误差|>2.5cm 或 |速度|>10cm/s → 扰动；|误差|<1.5cm 且 |速度|<5cm/s → 稳态
- 滞后切换防止模式抖动
- D 项使用 Kalman 原始速度直驱（零滞后，无 EMA）
- 扰动模式 D 上限 ±60°，稳态模式 D 上限 ±40°
- 稳态模式带慢速 I 项（速率 1.2, 上限 ±6°）纠正稳态偏移

### 4. 三模式触摸切换
- **模式 1**：双模式 PD（正常工作模式）
- **模式 2**：舵机 60°↔120° 来回摆动（2 秒周期，测试舵机）
- **模式 3**：舵机固定 90° 不动作（自由滚动测试）
- MaixCAM 触摸屏底部 30px 按钮栏切换
- 当前模式高亮绿色，FPS 日志标注 M1/M2/M3

### 5. Web 推流 + 录像
- MJPEG 实时视频流
- 浏览器端录像控制（开始/停止/下载/删除）
- 录像文件 `.mjpeg` 格式，可回放、可跳转进度条
- 跳帧编码降低 CPU 负载

### 6. UART 数据发送
- 组包格式：`AA 55 | pos_cm(2B LE) | CRC16(2B LE) | DD`
- 位置精度：厘米 × 100

## PID 控制器架构

```
Kalman 速度 (零滞后)
       │
       ├──→ 模式切换判断 (|err|>2.5 或 |v|>10 → 扰动模式)
       │
       ├──→ D 项 ──→ KD×vel ──→ [±60°/±40° 上限]
       │
       ├──→ P 项 ──→ KP×error ──→ [死区 ±0.2cm(仅稳态)]
       │
       └──→ I 项 ──→ 仅稳态 |err|<1.2cm 且 |v|<3cm/s 时生效
                            ──→ [±6° 上限]
       
       输出 = 90° + P + D + I
              ──→ 限速 (300°/s 稳态, 600°/s 扰动)
              ──→ 钳位 [30°, 150°]
```

### 参数表

| 参数 | 稳态 | 扰动 | 说明 |
|---|---|---|---|
| KP | 8.0 | 10.0 | 位置比例增益 (deg/cm) |
| KD | 4.0 | 7.0 | 速度微分增益 (deg·s/cm) |
| 死区 | ±0.2cm | 0 | P 项死区 |
| D 上限 | ±40° | ±60° | 防止 D 项失控 |
| 舵机限速 | 300°/s | 600°/s | 输出变化率限制 |
| 进入阈值 | — | \|err\|>2.5 或 \|v\|>10 | cm, cm/s |
| 退出阈值 | \|err\|<1.5 且 \|v\|<5 | — | cm, cm/s |
| I 速率 | 1.2 | 关闭 | deg/(s·cm) |
| I 上限 | ±6° | 0 | deg |

### 设计演进关键节点
1. **v1-v3**：串级 PID → 单环 PID（消除符号冲突），基础参数调优
2. **v4-v6**：I 项从连续积分改为自适应（近中心禁积防极限环），加预测性刹车（收 P + 增 D）
3. **v7-v8**：引入双速系统——Kalman 原速做判断（零滞后），EMA 速度驱 D（平滑）
4. **v9-v13**：去掉 EMA 改为零滞后直驱，双模 KD（扰动 8→7，D 帽 80→60→50），修复退出条件过严导致的近中心震荡
5. **v14-v16**：完全重写为干净的双模式 PD + 慢速 I，扰动全力输出不缩减，稳态精细控制，最终收敛到当前参数

## 使用方法

### 启动
1. 将 `main_yolo.py` 与 `model_310357.mud` 放入 MaixCAM2
2. 上电，舵机自动归中 90°
3. 等待绿色管道识别（串口打印 `Green tube locked!`）
4. 自动进入模式 1 双模 PD 控制

### 模式切换
- 触摸屏幕底部按钮栏切换 M1/M2/M3
- 或修改代码 `CURRENT_MODE = 1` (第 104 行) 重新上电

### Web 监控
- 浏览器打开 `http://192.168.43.130:5000`
- 实时画面 + 设备端录像 + 录像回放

## 注意事项

1. **舵机限速**：当前 300°/s（稳态）和 600°/s（扰动），修改 `S_RATE` / `D_RATE`
2. **管道颜色**：若更换管道颜色，需修改 `GREEN_THRESHOLD`（LAB 色域）
3. **模型文件**：`model_310357.mud` 路径回退为 `/root/models/mymodel/steelball/model_me2/`
4. **I 项**：仅稳态模式生效，扰动模式 I=0，避免积分助推过冲
5. **D 项零滞后**：直接使用 Kalman 原始速度，未加任何滤波。若舵机抖动明显，可考虑加回轻度 EMA
