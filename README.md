 **扩展板实物图**

 **扩展板引脚功能介绍图** 

 ![主板端口介绍](assets/主板端口介绍.png)

 - 电池供电接口：推荐使用直流 7.2V - 26V的电池进行供电。
 - 电源主开关：当主板使用电池进行供电时，此开关为主板整体供电开关。
 - 舵机接口1-2：将舵机插头直接连接至该接口，通过程序可以实现对舵机转动控制。且舵机供电电压可调。此接口有两个，可以接两个舵机。
 - 舵机电压调节电位器：通过旋动该电位器的调节旋钮，可以调节舵机接口的供电电压（主板在出货前默认已调整到6V左右）。
 - 电机驱动电源接口1-2：此接口用于向电机驱动提供电源。受开关控制且输出电压与电池电压相同。
 - 编码器接口1-2：适配逐飞科技增量式编码器直接连接。实现测速等功能。
 - 舵机电源指示灯：舵机电源正常工作时，该指示灯常亮。
 - 5V电源指示灯：当5V电源工作时，该指示灯亮起。（当核心板插在主板上，且核心板使用下载器供电时，该指示灯也可能微微亮起。）
 - CCD电源指示灯：当该电源工作时，该指示灯亮起。（当核心板插在主板上，且核心板使用下载器供电时，该指示灯也可能微微亮起。）
 - 3.3V电源指示灯：编码器、屏幕接口、蜂鸣器等其他3.3V外设稳压芯片。
 - 线性CCD接口1-2：以使用该接口采集CCD摄像头数据。
 - 灰度传感器接口：适配本公司GS08RA 8路灰度传感器，传感器输出为模拟量。
 - 无线模块接口（串口）：适配本公司的无线串口模块，从而实现无线串口通讯功能。
 - IO按键：与单片机IO相连，可以由用户程序控制。
 - 蜂鸣器：与单片机IO相连，可以由用户程序控制播放声音。
 - 测距模块TOF接口：可以直接连接本公司TOF测距模块，实现测距等功能。
 - 屏幕接口：适配本公司2.0寸IPS屏，1.8寸TFT液晶屏、1.14寸IPS液晶屏、OLED屏、IPS200PRO屏幕。
 - 有刷电机驱动信号接口1：可输出4路PWM信号，可以搭配本店铺电机驱动模块，实现控制2个电机的正反转及控速。
 - 姿态传感器接口：适配本公司IMU660RA、IMU963RA、IMU660RB、IMU660RC等姿态传感器模块。
