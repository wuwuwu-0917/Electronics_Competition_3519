# 钢球检测 UART 通信协议

## 硬件连接

| MaixCAM2 | MSPM0G3519 |
|----------|------------|
| U0T (TX) | RX |
| U0R (RX) | TX |
| GND | GND |

- 波特率：**115200**
- 数据位：8
- 校验位：无
- 停止位：1
- 电平：3.3V TTL

---

## 数据包格式

```
| 帧头  | 目标数 | 目标数据... | CRC16(LE) | 帧尾 |
| 2B    | 1B     | 10B × N     | 2B        | 1B   |
| AA 55 | COUNT  | DATA...      | CRC LE     | DD   |
```

### 帧头 (2字节)
固定值 `0xAA 0x55`，用于帧同步。

### 目标数量 (1字节)
`COUNT`：本帧包含的目标数量 (0-255)。

### 目标数据 (10字节/个)

| 偏移 | 字段 | 长度 | 类型 | 说明 |
|------|------|------|------|------|
| 0 | cx | 2B | uint16 LE | 中心 X 坐标（像素），范围 0~447 |
| 2 | cy | 2B | uint16 LE | 中心 Y 坐标（像素），范围 0~447 |
| 4 | w | 2B | uint16 LE | 框宽度（像素） |
| 6 | h | 2B | uint16 LE | 框高度（像素） |
| 8 | class_id | 1B | uint8 | 类别 ID，固定为 0 |
| 9 | score | 1B | uint8 | 置信度百分比，0~99，如 85 表示 85% |

> 图像分辨率：**448×448** 像素
  
> 坐标原点：图像**左上角** (0, 0)

> 字节序：所有多字节字段为**小端 (Little-Endian)**，低位在前

### CRC16 (2字节)

| 字段 | 长度 | 说明 |
|------|------|------|
| CRC16 | 2B LE | CRC16-CCITT (XMODEM)，多项式 `0x1021` |

**校验范围**：从 `COUNT` 到最后一个目标数据的最后一字节（不含帧头、CRC本身、帧尾）。

### 帧尾 (1字节)
固定值 `0xDD`，用于帧结束判断。

## 完整帧示例

假设有 2 个目标：

| 目标 | cx | cy | w | h | class | score |
|------|-----|-----|----|----|-------|-------|
| #0 | 281 | 174 | 47 | 50 | 0 | 85% |
| #1 | 300 | 200 | 35 | 38 | 0 | 73% |

### Hex 数据

```
AA 55                           ← 帧头
02                              ← 2个目标
19 01  AE 00  2F 00  32 00  00 55  ← 目标0: cx=281 cy=174 w=47 h=50 class=0 score=85%
2C 01  C8 00  23 00  26 00  00 49  ← 目标1: cx=300 cy=200 w=35 h=38 class=0 score=73%
XX XX                           ← CRC16 (根据上面数据计算)
DD                              ← 帧尾
```

### 解析

目标0：
- `19 01` → LE uint16 = `0x0119` = **281** (cx)
- `AE 00` → LE uint16 = `0x00AE` = **174** (cy)
- `2F 00` → LE uint16 = `0x002F` = **47** (w)
- `32 00` → LE uint16 = `0x0032` = **50** (h)
- `00` → class_id = **0**
- `55` → score = `0x55` = **85%**

## MSPM0G3519 接收流程

```
1. 读串口数据，拼接到缓冲区
2. 搜索帧头 AA 55
3. 读 COUNT (1字节)
4. 读 COUNT × 10 字节目标数据
5. 读 CRC16 (2字节 LE)
6. 读帧尾 DD
7. 对 COUNT + DATA 计算 CRC16，与收到的 CRC 对比
   - 一致 → 解析坐标，执行控制
   - 不一致 → 丢弃整帧，重新搜索帧头
```

### CRC16 C 语言参考

```c
// CRC16-CCITT (XMODEM), 多项式 0x1021
uint16_t crc16(const uint8_t *data, int len) {
    uint16_t crc = 0;
    for (int i = 0; i < len; i++) {
        crc ^= (uint16_t)data[i] << 8;
        for (int j = 0; j < 8; j++) {
            if (crc & 0x8000)
                crc = (crc << 1) ^ 0x1021;
            else
                crc <<= 1;
        }
    }
    return crc;
}

// 使用：校验 COUNT 到 DATA 末尾
uint16_t my_crc = crc16(&buffer[2], 1 + count * 10);  // buffer[2] 是 COUNT
```

## 注意事项

1. **开机日志**：UART0 开机时会输出系统日志（约几秒），STM32 端收到 `AA 55` 之前的所有数据应丢弃
2. **帧间隔**：约每 50ms 发送一帧（FPS ~20 时），单片机需在下一帧到来前处理完毕
3. **目标为 0**：当没有检测到目标时，不发送数据包
4. **坐标范围**：cx/cy 范围 0~447，w/h 范围不等，由实际检测框决定
5. **置信度**：score 为百分比整数 0~99，除以 100 得实际概率
